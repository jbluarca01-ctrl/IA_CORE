# ai_core

Cliente de IA multiproveedor (adaptadores OpenAI, NVIDIA NIM, Google Gemini, Anthropic y OpenRouter) con streaming SSE, excepciones tipadas por causa (autenticación, límite de tasa, timeout, red, servidor) y cancelación real de la conexión HTTP.

Extraído del monorepo de PRAXIA el 2026-09-25 para ser compartido, por dependencia de git, entre **PRAXIA** (uso propietario) y **Nettia** (PolyForm Noncommercial 1.0.0) sin duplicar código.
